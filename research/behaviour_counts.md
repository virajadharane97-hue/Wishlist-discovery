# Behaviour count table
Primary research, n=20 written responses. Counts are of stated
actions, not of agreement with a proposition.

## Counting rule
A behaviour is counted where the respondent names doing it as part of
how they handled the size question. Habitual and conditional phrasing
is counted ("I usually check the size chart", "I'll sometimes order
two sizes"). Stated non-behaviours are not counted ("I don't usually
ask anyone unless the item is expensive"). Respondent numbers are
listed against every count so any figure can be checked directly.

## Note on interpretation
Counts from a convenience sample of 20, not population estimates.
Several answers in the first six responses are a single line, so
counts should be read as "at least this many" rather than as precise
frequencies. Every count lists its respondents so the counting rule
can be inspected rather than trusted.
